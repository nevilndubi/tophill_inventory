# Tophill Inventory

Hospital equipment tracking and booking system. This repository currently contains the Task 0.1 monorepo scaffold only.

## Workspaces

- `apps/web` — Next.js App Router frontend
- `apps/api` — NestJS API
- `packages/shared` — shared TypeScript library

## Requirements

- Node.js 24.22.0
- pnpm 9.15.9

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

Linting rules and test suites are added by their dedicated later tasks.
